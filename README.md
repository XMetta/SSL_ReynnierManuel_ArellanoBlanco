# Sintaxis y Semántica de Lenguajes — UTN FRBA

Repositorio central de trabajos y laboratorios de la materia
**Sintaxis y Semántica de Lenguajes** — Ingeniería en Sistemas de Información,
Universidad Tecnológica Nacional, Facultad Regional Buenos Aires.

---

## Laboratorios

| # | Tema | Descripción | Tecnologías | Repositorio |
|---|------|-------------|-------------|-------------|
| 1 | Git y GitHub | Flujo de trabajo con ramas, commits, pull requests y control de versiones | Git, GitHub, Markdown | [lab-github](https://github.com/UTN-FRBA-SSL-LABS/laboratorios-xmetta/tree/main/labs/lab-github) |
| 2 | Proceso de compilación en C | Las cuatro etapas (preprocesamiento, compilación, ensamblado y enlazado), análisis de productos intermedios `.i`, `.s`, `.o`, inspección de tablas de símbolos con `nm` y AST con Clang | C, GCC, Clang, nm | [lab-compilacion-c](https://github.com/UTN-FRBA-SSL-LABS/laboratorios-xmetta/tree/main/labs/lab-compilacion-c) |
| 3 | Analizadores léxicos con Flex | Construcción de scanners: `yytext`, `yyleng`, definiciones ERX, variables globales, funciones de usuario y retorno de tokens al parser | Flex, C, expresiones regulares | [lab-flex](https://github.com/UTN-FRBA-SSL-LABS/laboratorios-xmetta/tree/main/labs/lab-flex) |
| 4 | Make | Automatización del proceso de compilación con Makefiles: reglas, dependencias, variables y targets especiales | Make, GCC, C | [lab-make](https://github.com/UTN-FRBA-SSL-LABS/laboratorios-xmetta/tree/main/labs/lab-make) |
| 5 | Strings en C | Manipulación de cadenas, gestión de memoria dinámica e implementación de funciones de string en C | C, memoria dinámica | [lab-string](https://github.com/UTN-FRBA-SSL-LABS/laboratorios-xmetta/tree/main/labs/lab-string) *(en curso)* |
| 6 | Testing en C | Pruebas unitarias en C: casos de prueba, validación de comportamiento y uso de frameworks de testing | C, testing | [laboratorio-testing-c](https://github.com/UTN-FRBA-SSL-LABS/laboratorios-xmetta/tree/main/labs/laboratorio-testing-c) |
| 7 | Bison | Construcción de parsers sintácticos: gramáticas libres de contexto, integración con Flex e implementación de un analizador sintáctico completo | Bison, Flex, C | [lab-bison](https://github.com/UTN-FRBA-SSL-LABS/laboratorios-xmetta/tree/main/labs/lab-bison) |

> Los laboratorios se cursan a través de **GitHub Classroom** bajo la organización
> [UTN-FRBA-SSL-LABS](https://github.com/UTN-FRBA-SSL-LABS). Este repositorio
> funciona como índice y referencia personal de la cursada.
> El repositorio consolidado con todos los laboratorios está en
> [laboratorios-xmetta](https://github.com/UTN-FRBA-SSL-LABS/laboratorios-xmetta).

## Contenidos de la materia

- Proceso de compilación: análisis léxico, sintáctico y semántico
- Herramientas: Flex (analizador léxico), Bison/YACC (análisis sintáctico)
- Lenguajes formales, gramáticas y autómatas
- Generación de código intermedio
