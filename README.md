# Sintaxis y Semántica de Lenguajes — UTN FRBA

Repositorio central de trabajos y laboratorios de la materia
**Sintaxis y Semántica de Lenguajes** — Ingeniería en Sistemas de Información,
Universidad Tecnológica Nacional, Facultad Regional Buenos Aires.

---

## Laboratorios

| # | Tema | Descripción | Tecnologías | Repositorio |
|---|------|-------------|-------------|-------------|
| 1 | Git y GitHub | Uso de control de versiones, flujo de trabajo con ramas, commits y pull requests | Git, GitHub, Markdown | [lab-git-github](https://github.com/UTN-FRBA-SSL-LABS/lab-git-github-XMetta) |
| 2 | Proceso de compilación en C | Las cuatro etapas del proceso (preprocesamiento, compilación, ensamblado y enlazado), análisis de productos intermedios `.i`, `.s`, `.o`, inspección de tablas de símbolos con `nm`, y fases internas del compilador (análisis léxico, sintáctico, semántico y AST) con Clang | C, GCC, Clang, Make, nm | [laboratorio-compilacion-c](https://github.com/UTN-FRBA-SSL-LABS/laboratorio-compilacion-c-XMetta) |
| 3 | Analizadores léxicos con Flex | Construcción de scanners: `yytext`, `yyleng`, definiciones ERX, variables globales, funciones de usuario y retorno de tokens al parser | Flex, C, expresiones regulares | [lab-flex](https://github.com/UTN-FRBA-SSL-LABS/lab-flex-XMetta) |

> Los laboratorios se cursan a través de **GitHub Classroom** bajo la organización
> [UTN-FRBA-SSL-LABS](https://github.com/UTN-FRBA-SSL-LABS). Este repositorio
> funciona como índice y referencia personal de la cursada.

---

## Contenidos de la materia

- Proceso de compilación: análisis léxico, sintáctico y semántico
- Herramientas: Flex (analizador léxico), Bison/YACC (análisis sintáctico)
- Lenguajes formales, gramáticas y autómatas
- Generación de código intermedio
